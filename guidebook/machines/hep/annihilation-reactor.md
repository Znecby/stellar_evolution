# 湮灭反应堆

终局能源：反物质 + 氢 → **直接向热压差网络供能**，不产蒸汽。

<BlockImage id="annihilation_reactor" scale="6" />

## 运行

- 输入容器：1 个反物质。
- 储罐：1 000 氢。
- 燃烧 1 200 tick，期间提供 **8 192 DP / 4 096 HP/t**。
- 烧完自动再取一份。
- 加入鎶-304 稳定岛添加剂 → 产能 ×1.5。

## 注意

- 它是热压差生成端：底排贴铜管，或任意一面贴铜块接入。
- 不产蒸汽，不需要压力管。
- 反物质和氢都要有；缺一份就停机。
