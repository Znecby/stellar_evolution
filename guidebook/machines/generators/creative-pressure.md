# 创造差压

调试用电源：容量极大，热流率可现场调整。

<BlockImage id="creative_pressure" scale="6" />

## 用途

- 测试机器 / 产线时，不想搭完整发电链。
- 调整热流率，观察机器倍速和 Jade 数值。
- 生存模式不作为正常能源。

## 注意

- 它仍然是生成端，遵循“容量累加、热流率取最大”。
- 热流率调到 0 时，网络倍速也是 0。
