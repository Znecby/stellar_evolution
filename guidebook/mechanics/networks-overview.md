# 四张网速查

先记一句话：**铜管传热，压力管传蒸汽，束流管传粒子，机械管传物品/流体。** 四张网各走各的，不要混接。

| 网络 | 载体 | 传什么 | 接机器规则 | 剪刀 |
|---|---|---|---|---|
| 热压差 | 铜管 + 铜块 | DP / HP | 大机器可铜块或底排铜管；单方块机器任意面铜管/铜块；小型消耗端贴铜块；储罐不接铜管 | 切断管臂，不影响网络判定 |
| 蒸汽 | 压力管 | 蒸汽数据（mB/t · ℃ · bar） | 底排 / 正下方，顶面不接 | 切断 |
| 束流 | 束流管 | 粒子流（9 种） | 侧面任意层 / 正下方，顶面不接 | 接上 / 断开 / Shift 换类型 |
| 机械物流 | 机械管 | 物品 / 流体 | 大机器底排 / 正下方；容器（含储罐）任意面 | 切换容器输入 / 输出 |

## 最容易搞错的四条

1. **热压差的小型消耗端必须贴铜块**（熔炉 / 木桶 / 机械土壤 / 热室）；**大机器可贴铜块或底排铜管**；**单方块机器任意面贴铜管/铜块即可**。
2. **机械管不进热压差网络**；铜管也不传物品 / 流体，**更不接储罐**。
3. **蒸汽和束流都只认自己的管**，压力管 / 束流管都不接铜管。
4. **束流管默认是空管且断开**，要用剪刀一段一段接；其他三种管是自动连、剪刀切断。
