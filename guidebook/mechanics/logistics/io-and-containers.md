# 容器与输入输出

## 默认输入

容器接上机器后默认是**输入**。手持剪刀右键容器，切换成**输出**。

- 输入容器：机器从这里抽原料。
- 输出容器：机器往这里放产物。
- 对外能力：输入容器只可灌入，输出容器只可抽出。

## 容器规格

| 容器 | 规格 |
|---|---|
| 铜箱子 | 单箱 27 格；双联 54 格，但只算一个容器 |
| <ItemLink id="reaction_chamber" /> | 54 格；对反应堆是专属燃料容器 |
| <ItemLink id="copper_tank" /> / <ItemLink id="steel_tank" /> / <ItemLink id="hardened_tank" /> | 8 / 32 / 128 桶每格；同档位合并 |
| 铜格栅 | 虚拟水源；含水 / 泵模式 |

## 储罐合并

| 档位 | 单格 | 3×3 | 3×3×32 最大 |
|---|---|---|---|
| 铜 | 8 桶 | 72 桶 | 2 304 桶 |
| 钢 | 32 桶 | 288 桶 | 9 216 桶 |
| 硬质 | 128 桶 | 1 152 桶 | 36 864 桶 |

- 同档位才合并；铜 / 钢 / 硬质相邻不拼。
- 水平只做 1×1 与 3×3，**2×2 不合并**；竖直 1–32 层。
- 3×3 时四角与正中是金属板，边中开窗。
- 拆掉任意一格后自动重算。

## 提示

- **大机器**没有内部槽 / 罐，原料和产物都要外部容器。
- **单方块加工机**有内部 3×3 料仓（右键打开），但产物仍然要正上方容器。
- 一台机器可以同时有多个输入容器和多个输出容器。
- 输入 / 输出方向存在机器里，拆了重放会重置为输入。
