# 配方结算

## 一次周期

机器每个周期按自己的配方类型，取第一条“条件满足 + 料够 + 放得下”的配方：

1. 从**输入容器**抽原料。
2. 把产物放进**输出容器**。
3. 抽料 + 放料在同一个事务里；任一步失败就整体回滚。

所以不会出现“原料被抽走了，产物却没放进去”。

## 并行

大多数大机器固定 **8 并行**：

- 热压差网络决定倍速，不改产率。
- 满速时一个周期最多完成 8 条配方。
- 输入不足 / 输出满 → 对应配方跳过，不会阻塞其它配方。

## 条件

配方可能带条件：

- 温度 / 压力 / 蒸汽等级
- 粒子流类型
- 催化剂 / 模具
- 机器机种

条件不满足时，该配方不会被选中；具体看 JEI 和 Jade。

## 常见错误

- 输出容器满了 → 产物放不下，整条事务回滚，机器看起来“不动”。
- 输入容器里混了多种原料 → 按配方表匹配；不相关物品不会消耗。
- IO 方向反了 → 原料进不去 / 产物出不来。
