# 排错

| 现象 | 常见原因 | 处理 |
|---|---|---|
| 机器不抽料 | 机械管没接在底排 | 管子挪到底排 / 正下方 |
| 机器不产物 | 输出容器满了 / IO 反了 | 清空输出，或用剪刀切输出 |
| 储罐接不上 | 机械管不属于该机器 / 被剪断 | 检查管网归属和剪刀切断 |
| 两台机器抢容器 | 管子桥接了两台机器 | 断开桥接，分别布线 |
| 热室不接物流 | 热室不是物流容器 | 用普通铜箱子 |
| `/se large` 看不到容器 | 容器没接在该机器的管网 | 检查管子和容器面 |

## 命令

`/se large`：瞄机器或容器，查看机器名、热压差接入、容器清单和输入 / 输出方向。

## 记住

- 机械管只走物流。
- 底排接管，容器（含储罐）任意面。
- 默认输入，剪刀切输出。
