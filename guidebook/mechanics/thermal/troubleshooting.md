# 排错

| 现象 | 常见原因 | 处理 |
|---|---|---|
| Jade 不显示热压差三行 | 方块没真正接入网络 | 检查铜管 / 铜块 / 生成端是否连通 |
| 大机器 0 / 0 | 铜块 / 底排铜管没接上 | 任意一格贴铜块，或底排贴铜管 |
| 机器不转但网络有数据 | 超载 / 倍速 0 / 物流缺料 | 看 Jade 状态行、`/se thermal`、输入容器 |
| 铜管发红闪 | 网络超载 | 增加容量，或减少消耗端 |
| 网络只有铜管，没有容量 | 没有生成端，或生成端停机 | 点燃熔炉 / 加燃料 / 接蒸汽涡轮机组 |
| 熔炉贴铜管不工作 | 小型消耗端必须贴铜块 | 加一格铜块 |
| 机械管接机器不生效 | 机械管不进热压差 | 换成底排铜管，或铜块 + 铜管 |

## 命令

- `/se thermal`：扫描准星所在网络，列出生成端、容量、热流率、消耗端、占用、状态。
- `/se large`：查看某台大机器的热压差接入与物流容器。
