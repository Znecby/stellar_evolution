# 负载与超载

## 三个公式

```
占用 DP = 基础热阻 × min(网络热流率, 该机满速阈值, 位置热流率上限)
倍速    = 网络热流率 ÷ 该机基准热流率
超载    = 总占用 > 总容量
```

- **刚好相等不算超载**。
- 超载时整张网的消耗端**全部停转**，不是只停最后接上的那台。
- 没有生成端（热流率 0）时，倍速也是 0。

## 算例

一台大机器：热阻 2、基准热流率 128 HP/t、8 并行。

| 网络热流率 | 占用 | 倍速 |
|---|---|---|
| 128 HP/t | 2 × 128 = 256 DP | 1.0 |
| 512 HP/t | 2 × 512 = 1024 DP | 4.0 |
| 1024 HP/t | 2 × 1024 = 2048 DP | 8.0（封顶） |

网络热流率继续涨，占用不再增加（该机满速阈值到了），但**倍速也不会再涨**，由机器自己夹到 8。

## 设计建议

- 多台机器共用一张网时，先算“总占用”，再配生成端容量。
- 容量不够会全停；热流率不够只是慢。
- 想要更快：提高网络热流率（换更高 HP/t 的生成端），不是堆容量。
