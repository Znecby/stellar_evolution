# 消耗端

## 大机器

- 任意一格、任意一面贴**铜块**，或在**底排**贴**铜管**接入。
- 普通大机器固定 **8 并行**，满速时占用 = 热阻 × 基准热流率 × 8；粒子源 / 回旋加速器 / 聚变仪等特殊机看各自页面。
- **固定多方块**（焦化炉 / 质量投射轨道炮）：控制器本身不是消耗端，铜块或底排铜管要贴**机械物流仓**；见[焦化炉](../../machines/industry/coke-oven.md) / [质量炮](../../machines/industry/mass-driver.md)。
- 热阻 / 基准热流率按机种不同，见[通用大机器](../../machines/common-large-machine.md)。

## 单方块加工机

- 破碎机 / 压模机 / 轧线 / 钢炉 / 焊接机 / 开采钻：**任意面贴铜管或铜块**即可。
- 热阻 2、基准 64 HP/t；机内有自己的 3×3 料仓（焊接机 1×3），不走机械管。
- 9 并行（焊接机不并行），产物进正上方容器；详见[单方块加工机](../../machines/single-block/single-block-machines.md)。

## 小型消耗端

| 消耗端 | 占用 | 说明 |
|---|---|---|
| 熔炉 / 烟熏炉 / 高炉 | 16 DP @ 8 HP/t | 网络能量代替燃料 |
| 木桶 | 16 DP @ 8 HP/t | 钓鱼产出 |
| 机械耕地 / 沙地 / 灵魂沙地 | 16 DP @ 8 HP/t | 催熟 / 自动收割 |
| 机械草地 | 32 DP @ 8 HP/t | 同上，耗能翻倍 |
| 热室 | 热阻 4 | 铜箱子底部垫铜块 |

全部都要**贴着铜块**，不能直接贴铜管。

## Jade

消耗端 Jade 第 2 行显示的是**有效热流率**：`min(网络热流率, 该机满速热流率)`。它到顶后不再上涨，代表这台机器已经满速，不是网络停了。
