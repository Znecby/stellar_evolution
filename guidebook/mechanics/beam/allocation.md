# 分配规则

## 每 tick 现算

束流网络不存粒子。每 tick：

1. 汇总所有源的本 tick 产出。
2. 收集所有消费者的需求。
3. 按 **max-min 公平**分配。
4. 消费者拿到的份额当 tick 用掉。

## 例子

| 供给 | 需求 | 分配 |
|---|---|---|
| 10 | [2, 10] | [2, 8] |
| 3 | [10, 10, 10] | [1, 1, 1] |
| 100 | [0, 50] | [0, 50]（需求 0 不参与） |

需求 0 的消费者不占配额；需求小的先满足，剩下的均分。

## 对撞机

对撞机同时是消费者和源：

- 吃两路束流才出产物。
- 运行时向外喷一路输出流。

所以它既会出现在需求列表里，也会出现在源列表里；两个判断互相独立。
