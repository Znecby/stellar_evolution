# 排错

| 现象 | 常见原因 | 处理 |
|---|---|---|
| 管子中心还是安山岩 | 还是空管 | 用剪刀接上，或让有输出流的机器给它定型 |
| 接了机器但网络没反应 | 那一端没接上 | 剪刀右键对准的那一端 |
| 两种流接不到一起 | 类型不同 | 正常；用 Shift + 右键统一整段类型 |
| 消费者收不到 | 没需求 / 类型不匹配 / 没接上 | 看机器 Jade 和配方 |
| 对撞机不工作 | 两路束流没同时满足 | 检查两路管子、类型、供给 |
| 源有产出但网络速率 0 | 源没接到管 / 管没接上 | 检查底排、侧面层数、剪刀 |

## 记住

- 束流管**默认断开**，这是它和其他管最大的区别。
- 网络只汇总同类型的源；消费者不校验类型，吃不吃由它自己的配方决定。
