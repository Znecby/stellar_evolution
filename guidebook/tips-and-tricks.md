# 技巧与排错

- **四张网不要混**：铜管传热、压力管传蒸汽、束流管传粒子、机械管传物品/流体。
- **热压差的小型消耗端必须贴铜块**（熔炉 / 木桶 / 土壤 / 热室）；**大机器可贴铜块或底排铜管**；**单方块机器任意面贴铜管/铜块即可**。
- **机械管在大机器底排接管，容器任意面**；蒸汽管也是底排；束流管可以接侧面任意一层。
- **束流管默认空管且断开**，用剪刀接；Shift + 右键整段换类型。
- **容器默认输入**，用剪刀右键容器切输出；忘了切，产物会把输入容器塞满。
- **储罐三档**：铜 8 桶/格、钢 32、硬质 128；同档位才合并，水平只做 1×1 / 3×3，竖直可叠到 32 层，2×2 不合并。
- **铜管不接储罐**；储罐只走机械管 / 流体管道，机械管可接任意一面。
- **热力引擎正下方放容器塞燃料**，不再要求点燃的熔炉；燃烧引擎固体 4096 DP / 512 HP/t，液体更强。
- **焊接机**：固定顺序 钨板/铜板/钨板、下方储罐**助焊剂 25 mB**、上方容器收产物；助焊剂 = 硼砂 + 水（调浆机）。坚固不锈钢 / 高速钢焊接板改用 **25 mB 氩气**（氩弧焊，氩气来自液态空气分馏）。
- **钢炉**：原版熔炼配方、9 格并行，产物进正上方容器。
- **焦化炉**：3×3×4 红砖 + 砖半砖，控制器在侧面中心，另外三面是物流仓；热压差贴仓室，机械管只接仓室正面。
- **燃料等级别灌错**：燃烧引擎吃 LOW / MEDIUM / HIGH；工业内燃机组只吃 MEDIUM / HIGH；联合燃气机组只吃 GAS / AERO；火箭吃 ROCKET；甲醇、萘不是燃料。
- **三台新机组**：工业内燃氧气助燃、燃气轮机铜格栅供水产汽、火箭引擎真空可用但尾焰 8 格秒杀。
- **煤 / 木化工共用焦化炉**；煤焦油走分馏出 BTX / 萘 / 苯酚，木醋液走分馏出醋酸 / 甲醇 / 丙酮。
- **超载会全停**：Jade 铜管发红闪时，先加容量或减消耗端。
- **热压差容量看总和，热流率看最大**；多放低 HP/t 引擎只会加容量。
- **反应堆先接水再接压力管**，没有压力管会“无法输出蒸汽”，没有蒸汽涡轮机组则末端排气。
- **裂变堆只认反应仓**，铜箱子里的燃料棒不算；一台堆只放 1 个仓。
- **聚变仪缺水会锁死**，稳定值低于 20 要取出芯核重放。
- **对撞机要两路束流**；加速环贴着对撞机才计数。
- **开采钻产物进正上方容器**，没有容器就停机。
- **Jade 第 2 行到顶不代表停机**，是机器已经满速。
- **`/se thermal` 和 `/se large` 是最快的排错入口**；比猜管子的接法快。
- 配方优先看 JEI；书里只讲机制和接法。
