# 流体

流体桶都在创造页「流体」页签里；生存里用桶 / 储罐 / 机械管搬运。

| 线 | 例子 | 用途 |
|---|---|---|
| 生化 | 生物质浆、发酵液、乙醇、酶液、培养基、沼气 | 生化线 |
| 石化 | 原油、石脑油、重整油、普通汽油、高辛烷汽油、含铅汽油、柴油、航空煤油、火箭燃料 | 燃料 / 塑料 / 橡胶 |
| 空气分馏 | **液态空气、氮气、氩气、氦气**（氦气与裂变线共用同一流体） | 合成氨 / 氩弧焊 / 空分副产 |
| 煤化工 | 煤焦油、合成气、净化合成气、焦炉煤气、发生炉煤气、SNG、二甲醚、合成航煤、BTX、萘、乙炔、氯乙烯、醋酸乙烯、**煤水浆、煤液化油** | 焦化 / 气化 / 电石 / PVC / 燃料 / 煤液化 |
| 木化工 | 木焦油、木醋液、松节油、杂酚油、糠醛、糠醇、松节油-硝酸、糠醇-硝酸、乙醇氧 | 木干馏 / 分馏 / 火箭燃料 |
| 燃料 | 29 种液体 / 气体燃料 | 见[燃料表](fuels.md) |
| 裂变 | 六氟化铀、氦气等 | 燃料循环 |
| 选冶 | 硫酸、浸出液等 | 矿石处理 |
| 基岩 | 同位素溶剂、萃取液 | 无限资源 |
| 焊接 | **助焊剂**（硼砂 + 水）、**氩气** | 焊接机；氧气已不再用于焊接 |

## 注意

- 蒸汽 / 超临界蒸汽流体只保留给 JEI 看配方；实际蒸汽走压力管数据网络。
- 原油像水一样可以游泳 / 浮起，但不要当水源。
- 流体储存用[储罐](../machines/industry/tank.md)：铜 8 桶/格、钢 32 桶/格、硬质 128 桶/格；机械管可接任意一面，**铜管不接储罐**。
- 氧气由生化反应器的**水电解**产出：水 1 000 mB → 氢气 1 000 + 氧气 500，需要嗜热高温带且热流率 ≥ 64 HP/t；现在主要用于内燃 / 燃气助燃、硝酸与火箭燃料，不再用于焊接。
- 助焊剂由**调浆机**产出：硼砂 ×1 + 水 500 → 助焊剂 500。
- 氩气由**不锈钢格栅 + 分馏塔**产出：液态空气 5 000 → 氮气 3 840 + 氧气 1 050 + 氩气 100 + 氦气 10；不锈钢格栅仅主世界、任意一面贴空气方块时供气。
