# 材料

材料分几大类，全部可在创造页「基础材料 / 合金材料 / 进阶组件 / 高级组件 / 杂项物品」里找到。

| 类别 | 例子 | 用途 |
|---|---|---|
| 铜 / 钢 | 铜锭、钢板、钢杆 | 基础设施、机器框架 |
| 合金 | 不锈钢、钨钢、镍基、钛合金等 | 大机器、耐高温件 |
| 元素粉 | 铬、镍、铌、钛、铝、钼、锆 | 合金配料 |
| 生化 | 生物质、酶、培养基、抗生素 | 生化线 |
| 石化 | 塑料、橡胶、树脂、溶剂、PVC | 电路、密封、管件 |
| 煤化工 | 焦炭粉、煤炭粉、电石、活性炭、针状焦、石墨电极、PVC、尿素 | 气化 / 电石 / 碳素 / 裂变石墨 / 煤液化 |
| 木化工 | 木炭（原版）、木炭粉、松香、醋酸纤维、硝化纤维 | 燃料 / 助焊剂 / 塑料替代 / 发射药 |
| 焊接 | 焊接板、坚固钨 / 铅 / 不锈钢 / 高速钢焊接板、助焊剂桶、氩气桶 | 焊接机 / 开采钻整机 |
| 燃料 | 29 种液体 / 气体燃料 | 见[燃料表](fuels.md) |
| 选冶 / 盐湖 | 粗矿、精砂、硼砂、氯化钠 | 元素来源 |
| 基岩 | 同位素溶剂、萃取产物 | 无限资源线 |
| 裂变 / 聚变 | 铀、钚、锂、氘氚芯核 | 核线 |

## 提示

- 物品配方看 JEI；材料之间大多可以互相替代或作为中间体。
- 带 3D 图标的物品通常是组件，平板图标通常是材料。
- 焦炭的 id 仍是 `coke`，显示名已改为**焦炭粉**；煤炭 / 木炭用破碎机磨成粉（1 出 1），粉是煤化工与活性炭的正式进料。
