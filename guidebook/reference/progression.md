# 进度路线

| 阶段 | 你要做的事 | 关键内容 |
|---|---|---|
| 热压差 | 铜管 + 铜块 + 热力引擎（容器燃料） | [第一张热压差网络](../getting-started/first-heat-network.md) |
| 单方块加工 | 破碎 / 压模 / 轧线 / 钢炉 | [单方块加工机](../machines/single-block/single-block-machines.md) |
| 大机器 | 2×2×2 + 铜块 / 底排铜管 + 机械管 | [通用大机器](../machines/common-large-machine.md) |
| 生化 | 机械土壤 → 调浆 → 发酵 → 反应釜 | [生化线](../example-setups/bio-line.md) |
| 石化 | 原油 → 分馏 → 裂解 → 聚合 | [石化线](../example-setups/petro-line.md) |
| 煤化工 | 煤 → 焦化炉 → 焦炭 / 煤焦油 / 焦炉气 → 气化 / 分馏 / 电石 | [化工总览](../reference/chemistry.md) |
| 煤液化 | 煤 → 破碎 → 煤炭粉 → 煤水浆 → 煤液化油 → 分馏（后期替代原油） | [化工总览](../reference/chemistry.md) |
| 木化工 | 原木 → 焦化炉 → 木炭 / 木焦油 / 木醋液 / 松节油 | [化工总览](../reference/chemistry.md) |
| 空气分馏 | 不锈钢格栅 → 分馏塔 → 氮气 / 氩气 / 氦气 | [石化线](../example-setups/petro-line.md) |
| 燃料 / 机组 | 燃料表 → 工业内燃 / 燃气轮机 / 火箭 | [燃料表](../reference/fuels.md) |
| 选冶 / 基岩 | 矿石处理、同位素溶剂萃取 | JEI「选冶 / 基岩」分类 |
| 焊接 | 助焊剂 → 焊接机 → 坚固钨焊接板；中期氩气 → 不锈钢 / 高速钢焊接板 | [焊接线](../example-setups/welding-line.md) |
| 裂变 | 铀矿 → 燃料棒 → 反应堆 → 蒸汽涡轮机组 | [裂变电站](../example-setups/fission-power-plant.md) |
| 聚变 | 聚变芯核 → 缪子聚变仪 | [缪子聚变](../example-setups/muon-fusion.md) |
| 高能物理 | 回旋 → 粒子源 → 辐照 / 对撞 → ADS / 湮灭 | [束流链](../example-setups/beam-chain.md) |
| 装备 | 钢 / 钨钢工具与护甲 | JEI / 创造页「装备」 |
