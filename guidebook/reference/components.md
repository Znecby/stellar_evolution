# 组件

组件是机器配方的“骨架”，大多带 3D 图标。

| 类别 | 例子 |
|---|---|
| 结构 | 轴承、机械框架、精密重型框架、活塞组件 |
| 电气 | 电阻、电容、传感器、电动马达、磁通线圈、伺服、温控器、控制模块 |
| 电子 | 电路板、芯片、电路基材 |
| 流体 | 流体单元、锆合金管、PTFE 管、耐候软管 |
| 密封 | 橡胶板、油封、高温密封件 |
| 裂变 | 燃料芯块、控制棒、反射模块、锆管、离心机转子 |
| 聚变 / 高能 | 聚变芯核、稀土磁体、铂族催化剂、超导线 |

## 提示

- 组件配方看 JEI；很多组件是跨线材料，不要只盯一条线。
- 3D 图标物品在「进阶组件 / 高级组件」页；普通材料在「基础材料」页。
