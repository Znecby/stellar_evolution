# Security Policy

## Supported versions

Only the latest release receives security fixes. Pre-release builds are provided for testing and may contain known issues.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Use GitHub's private vulnerability reporting:

https://github.com/Znecby/stellar_evolution/security/advisories/new

Include:

- affected version
- steps to reproduce
- impact
- relevant logs or crash reports

You should receive a response within 7 days. Once a fix is available, a new release will be published and the advisory disclosed.
